# Casos de uso

| Caso de uso | Objetivo o breve descripción |
|--------------|--------------|
| 1.  Registrar usuario| Como usuario no logueado quiero registrarme en el sitio con nombre único, correo de recuperación único y contraseña para ingresar y operar dentro del sitio web.|
| 2. Iniciar sesión| Como usuario no logueado quiero iniciar sesión con nombre y contraseña para operar dentro del sitio web.|
| 3. Modificar contraseña olvidada| Como usuario no logueado quiero tener una opción en el “inicio de sesión” para restablecer mi contraseña en caso de olvido.|
| 4. Cerrar sesión| Como usuario logueado quiero cerrar sesión para no continuar operando dentro del sitio web.|
|5. Mostrar bloque explicativo  | 	Como usuario logueado quiero ver un bloque explicativo del sitio web al cerrar sesión para confirmar el cierre de sesión y conocer algunas características sobre el sitio. |
| 6. Actualizar contraseña| 	Como usuario logueado quiero actualizar mi contraseña desde mi cuenta para mantenerla actualizada.|
| 7. Actualizar correo de recuperacion| 	Como usuario logueado quiero actualizar mi correo desde mi cuenta para mantenerlo actualizado.   |
| 8. Actualizar descripción de perfil| 	Como usuario logueado quiero actualizar la descripción de mi perfil para mantenerla actualizada.|
| 9. Actualizar foto de perfil| 	Como usuario logueado quiero actualizar la imagen de mi perfil para mantenerla actualizada.|
| 10. Consultar mis posteos en mi perfil| 	Como usuario logueado quiero consultar mis posteos en mi perfil para ver y gestionar el contenido que he publicado.|
| 11. Consultar posteos calificados| 	Como usuario logueado quiero consultar los posteos que he calificado en mi perfil para llevar un seguimiento de mis interacciones y opiniones sobre otros contenidos.|
| 12. Consultar otros perfiles| 	Como usuario logueado quiero consultar los perfiles de otro usuario para ver el contenido que ha publicado.|
| 13. Consultar posteos en el sitio	| Como usuario logueado quiero consultar todos los posteos realizados en el sitio para ver el contenido que se va publicando|
| 14. Ver detalle posteo| 	Como usuario logueado quiero consultar el detalle de un posteos que seleccione para ver el resto del contenido del posteo.|
| 15. Crear posteo| 	 Como usuario logueado quiero crear un nuevo posteo para compartir con otros usuarios y construir mi perfil y visibilidad dentro de la plataforma.|
| 16. Modificar posteo propio|  	Como usuario logueado quiero modificar mis posteos para mantener actualizada la información que publico o corregir errores.|
| 17. Eliminar posteo propio| Como usuario logueado quiero eliminar mis posteos para mantener mi perfil con contenido relevante y actualizado.|
| 18. Agregar comentario| 	Como usuario logueado quiero agregar comentarios a  posteos para interactuar con estos y otros usuarios.|
| 19. Eliminar comentario propio	| Como usuario logueado quiero eliminar un comentario propio para retirar información que ya no quiero compartir o corregir un error si fuera el caso.|
| 20. Consultar comentarios en un posteo| 	Como usuario logueado quiero consultar los comentarios en un posteo para conocer las opiniones de otros usuarios, obtener retroalimentación si el posteo es mío y estar al tanto de nuevas respuestas.|
| 21. Agregar calificación| 	 Como usuario logueado quiero seleccionar un puntaje en un posteo para expresar mi opinión al respecto, contribuir en la valoración y ayudar a identificar posteos relevantes.|
| 22. Modificar calificación| 	Como usuario logueado quiero actualizar una calificación que haya realizado en un posteo para mantener actualizada mi opinión al respecto y contribuir en la valoración.|
| 23. Consultar calificaciones en un posteo| 	Como usuario logueado quiero consultar la valoración en un posteo para conocer las opiniones que recibió el mismo y obtener retroalimentación si el posteo es mío.|
| 24. Explorar mejor calificados| 	Como usuario logueado quiero consultar los posteos con mayor Qualif para encontrar rápidamente el contenido mas relevante valorado por la comunidad.|
| 25. Explorar posteos random| 	Como usuario logueado quiero consultar posteos con Qualif random para descubrir contenido variado que probablemente no encontraría en las búsquedas habituales, tener una experiencia mas dinámica y dar visibilidad a posteos con menos exposición.|
| 26. Buscar perfiles	| Como usuario logueado quiero buscar perfiles de usuario para encontrar usuarios específicos dentro de la plataforma y conocer mas sobre la actividad de otros usuarios.|
