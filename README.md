

## Sistema de Gestión de Contenidos (Blog)
Este proyecto consiste en el análisis, diseño y desarrollo de un sistema web para la gestión de publicaciones, orientado a centralizar la creación, visualización e interacción de contenido por parte de usuarios. 
El foco principal del proyecto está en la definición de requerimientos, modelado del sistema y documentación funcional, replicando el enfoque de un analista funcional en un entorno real.


## Alcance funcional de la plataforma
- Gestión de publicaciones.
- Gestión de usuarios.
- Registro de comentarios.
- Sistema de calificación de contenido.

Durante el desarrollo se trabajó en:

- Relevamiento y definición de requerimientos
- Elaboración de historias de usuario
- Modelado de casos de uso (CU)
- Diseño de modelo de dominio y datos
- Priorización mediante product backlog
- Documentación funcional para soporte a desarrollo
